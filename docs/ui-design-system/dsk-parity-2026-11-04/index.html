DSK analyzer: původní WPF a upravená Avalonia

Nezměněné rendery skutečné WPF aplikace a Windows/Linux testovacích oken Avalonia ze 4. 11. 2026. Kliknutí otevře původní PNG v plném rozlišení. WPF používá systémové DPI (150 %), Avalonia headless 96 DPI; zdroje PNG nejsou oříznuté, přebarvené ani přepočítané. Galerie porovnává rozložení, vykreslená data a ovládací prvky; nepotvrzuje pixelovou identitu fontů nebo systémových dekorací.

Manifest originálních souborů a SHA-256

Disk Map · Disk Surface · Track / Sector · Issues · Statistics · Tracks · Unrolled MFM detail

Disk Map

Čistý FSMZ obraz s jedním souborem FIRST, 40 cylindrů × 2 strany.

Disk Surface

Stejný čistý obraz; Role, Equal per descriptor, All sides, bez výběru.

Track / Sector

Stejný obraz se ST1=0x20 u descriptoru 1 tracku 0; vybrán právě tento sektor.

Issues

Stejný FDC nález; All filtry. V Avalonia testu je navíc označen řádek nálezu.

Statistics

Statistiky téhož obrazu s FDC nálezem a kontrolním součtem aktuálního obrazu.

Tracks

Původní kompletní sloupce geometrie a descriptor order nad stejným obrazem.

Unrolled MFM detail

Čistý obraz, track 0 / descriptor 0, Fit sector + zoom 80×. Vložený skutečný výstup Core encoderu.
