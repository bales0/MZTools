# DSK analyzer a Visual Inspector podle WPF — 4. 11. 2026

Avalonia DSK analyzer používá původní uspořádání a ovládání WPF, včetně samostatného vizuálního inspektoru. Výpočty, mapování filesystemu, diagnostika a MFM encoder nadále pocházejí ze sdíleného Core.

- **Disk Map:** souhrn analýzy, Physical / Logical order, Clear selection, Copy / Save report; vlevo původní pevné buňky tracků, vpravo počítadla All / Errors / Unsafe / Warn. / Info, záložky Blocks / Issues, filtr a vysvětlení závažnosti, strukturované Selection / sector details. Dělítka umožňují měnit velikost panelů. Hex buffer nabízí fyzický sektor i skutečně mapované CP/M bloky. Hex a patch otevírají existující transakční nástroje. Lišta při mapě skrývá souborové operace stejně jako WPF; dolní informace zahrnují kontejner, geometrii, kapacitu a boot detekci.
- **Visual Inspector:** původních pět záložek Disk Surface, Track / Sector, Issues, Statistics, Tracks; výběr tracku a strany, Equal per descriptor / Relative to stored bytes, všech šest vrstev Role, Ownership, Issue severity, FDC status, Data length anomalies, Current selection. Povrch i track přenášejí původní geometrii a hit-test nad stejným snapshotem.
- **Výběr a navigace:** sdílení s editorem oběma směry, Ctrl / Shift, Esc, pan, zoom, Fit, dvojklik na Hex, výběr vlastníka a navigace z nálezu. Rozpracovaný hex buffer nelze výběrem z inspektoru zahodit. Změna obrazu obnoví snapshot i on-demand MFM cache.
- **Nálezy a statistiky:** souběžné filtry Severity / Type / Role / Owner, Jump to issue a Finding details, všechny původní sloupce sektorů a tracků, skutečné statistiky včetně provenance, SHA-256 a creator padding. Export diagnostiky podporuje TXT / CSV / JSON, vybrané sektory lze exportovat/importovat. Tabulky podporují řazení kliknutím a kopírování hodnot s hlavičkami.
- **MFM a detaily:** Unrolled MFM detail je vložený pod povrchem, s Fit track, Selected sector a zoomem; při zvětšení povrchu alespoň 6× se zpřístupní automaticky. Zobrazuje skutečný výstup Core encoderu, při detailním zoomu HEX, clock/data buňky a přechody. U HFE používá uložené buňky, weak masky a index/timing/control značky. DSK se nevydává za měřený flux. Floating selection details má strukturovaný report a akce Open Hex / Select owner file; otevření se odkládá do zobrazení vlastníka a okno lze zavřít i znovu otevřít.

Regrese `DskVisualParityTests` kontrolují geometrii, vrstvy, filtry, skutečný skok na nález, řazení a kopírování hodnot, propojení výběru, nezměněné zdrojové bajty, ochranu hex draftu, obnovení snapshotu a opakované otevření plovoucího okna. U DSK i HFE porovnávají MFM buňky s Core a ověřují vykreslení skutečných bajtů a buněk. Nativní test opakuje hlavní DSK workflow na Windows a Linuxu.

[Galerie původního WPF a Avalonia](ui-design-system/dsk-parity-2026-11-04/index.html) obsahuje nezměněné PNG, původ souborů a jejich SHA-256. WPF má systémové DPI, headless Avalonia render 96 DPI. Shoda rozložení, dat a otestovaných funkcí neznamená pixelovou identitu systémových dekorací, fontů a theme rendererů na všech platformách. Galerie rozlišuje čistou fixture, fixture s uloženým FDC statusem a detail MFM.
