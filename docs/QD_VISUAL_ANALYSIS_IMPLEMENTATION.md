Tools becomes available in the QD workspace; audio analysis stays in the audio workspace. The existing eight-row Disk Map remains available separately.

The five pages are Disk Surface, Regions, Files, Findings and Statistics. Disk Surface now follows the DSK layout: circular map above, adjustable row splitter, and an unrolled MFM panel below with Fit track / Selected region / Zoom controls. The panel is initially visible and can be collapsed with the same Unrolled MFM detail checkbox used by DSK. The QD continuous stream follows one continuous 32-turn Archimedean spiral, clockwise from the outer start to the inner end. Radius decreases continuously through each revolution; colored regions never restart as separate circles. The spiral is explicitly schematic, not measured track geometry. The circular map and unrolled detail share exact region identities and Ctrl/Shift selection. Selecting the surface fits the corresponding detail. Wheel zoom anchors to the pointer, dragging pans, and Home/Fit restores each view independently. Files/Regions tables support extended selection, sorting, column resizing and copying. Double-click opens/fits the unrolled detail. Esc clears selection.

Selecting files highlights every corresponding region; region selection selects the corresponding native files in the main editor. Synchronization guards preserve region focus rather than replacing it with every region of the owning file. Non-SHARP decoded host blocks/sectors have no invented SHARP file owner. The floating detail checkbox opens an owned modeless report without activating it. Its position and size persist across selection changes; closing it disables automatic reopening. HEX preview uses the actual selected region's bytes through the existing HexBrowser.

## Data and provenance

`QuickDiskVisualSnapshot` clones the image before using `QuickDiskLayoutBuilder.Read`. MZQ, QDF and SHARP legacy positions are logical container-byte offsets. HxC and FlashFloppy positions are actual stored track bitcells, LSB-first, with container track offset and switch window shown in Statistics. Bit rate is container metadata, not a measured timing/flux signal. A modified/new document uses the existing writer to build a separate preview, prominently marked Rebuilt preview and not original positions. No generated DSK MFM is involved.

Physical host analysis is retained by the existing layout reader and reused rather than decoding the same track again for the inspector. Native SHARP files use the existing validated frame sequence/CRCs. QDF frame CRCs differ from the literal CRC markers in compact MZQ/legacy storage; statistics state this distinction. Roland, Akai and MO5 content uses existing host-decoder bytes and confidence. Unknown, incomplete and bad-checksum findings remain visible; unassigned regions are not certified free space. A failed logical decode exposes the original container bytes with an error instead of inventing files. If rebuilding the current edited document fails, the previous snapshot is explicitly unavailable for navigation/export until a valid refresh.

At sufficient zoom the bottom detail draws HEX bytes, individual bit values and a dark-blue step signal, matching the DSK presentation and region palette (orange metadata, green data, blue framing, purple CRC, gray gaps). Each transition comes from adjacent cell values. For physical QD these are original stored cells, not analog flux. For logical MZQ/QDF/legacy, the existing QuickDiskMfmCodec lazily encodes a snapshot copy of the logical container bytes; the header explicitly says GENERATED and not stored track positions. This illustrative encoding includes container framing and is not a reconstructed drive-ready QD track. Coordinates and file ownership remain logical bytes; 16 generated cells correspond to one byte. Native SHARP decoding follows the first data-cell position and little-bit ordering already used by the layout. Host HEX uses actual decoder output. MO5 mapped sectors include headers/sync/checksum while HostBytes contains payload only: payload HEX starts at the decoder-derived `region.End - (payload.Length + 1) * 16`, verified independently against the host bitstream decoder. Clock/data phase is frame dependent and is not asserted globally. Red strips mark findings with proven coordinate bounds; global warnings have no invented location. Findings double-click navigates to overlapping regions.

Statistics includes source provenance, SHA-256, host/confidence, integrity interpretation, unit/length/file/region/finding counts and physical offset/window/nominal bit rate where available. TXT, CSV and JSON exports preserve these distinctions. Report generation runs off the UI thread; cancel/close prevents destination replacement. Writes use a temporary sibling file and only replace the destination after successful completion. Source bytes and document modified state remain unchanged.

## Lifecycle and rendering

An open inspector refreshes when the main document refreshes and closes when it ceases to be QD or the main window closes. Reopening the existing inspector keeps its zoom. Snapshot replacement clears old region references and rebuilds selections through current identities. Floating reports follow current selection and never reposition themselves after initial placement.

Rendering uses two custom WPF elements. Cached spiral ribbons follow the existing region intervals, with visible spaces between turns; the detail clips to its visible interval and renders only visible HEX/cells/transitions. There is no element per cell or full-track signal path. Generated cells are cached per snapshot instead of encoded on each paint. The minimum zoom interval is 16 stored cells or one logical byte (16 generated cells); coordinate math clamps to the available image and rejects invalid zoom factors. Exports capture their snapshot independently of later UI changes.

Approved DSK-style follow-up validation: all five source formats compare displayed signal bits against original stored cells or the existing encoder, including bounds and source preservation. UI checks cover spiral logical/physical hit mapping, continuity and inverse mapping at angular seams, empty inter-turn gaps, 60x zoom, anchored circular zoom, shared surface/detail selection, visible step transitions for both stored and generated data, collapsible lower pane, bounded rendering, and existing floating/table/lifecycle behavior.
